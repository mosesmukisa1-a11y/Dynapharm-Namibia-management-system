# 1. STOCK MUST NOT MOVE WITHOUT BATCH + EXPIRY

## Required APIs

### A. Import stock

```http
POST /api/stock/import/receive
```

### Request body

```json
{
  "supplierId": "sup_001",
  "warehouseId": "wh_windhoek",
  "items": [
    {
      "productId": "prod_001",
      "quantity": 100,
      "batchNo": "BATCH-001",
      "expiryDate": "2027-03-31",
      "unitDP": 300,
      "unitCIF": 180
    }
  ],
  "receivedBy": "user_001",
  "notes": "Initial import"
}
```

### Validation

* reject if `batchNo` missing
* reject if `expiryDate` missing
* reject if quantity <= 0

---

### B. Dispatch stock

```http
POST /api/stock/dispatch/create
```

### Request body

```json
{
  "sourceWarehouseId": "wh_windhoek",
  "destinationBranchId": "branch_cbd",
  "items": [
    {
      "productId": "prod_001",
      "batchNo": "BATCH-001",
      "expiryDate": "2027-03-31",
      "quantity": 20
    }
  ],
  "preparedBy": "user_001"
}
```

### Validation

* dispatch must fail if batch missing
* dispatch must fail if expiry missing
* dispatch must fail if stock for exact batch not available

---

### C. Branch receipt

```http
POST /api/stock/dispatch/confirm-receipt
```

### Request body

```json
{
  "dispatchNoteId": "disp_001",
  "branchId": "branch_cbd",
  "receivedBy": "user_002",
  "signature": "Naem",

    {
      "productId": "prod_001",
      "batchNo": "BATCH-001",
      "expiryDate": "2027-03-31",
      "qtyReceived": 20,
      "discrepancyNote": ""
    }
  ]
}
```

### Required effect

* branch inventory increases by exact batch
* movement created
* stock reports update
* batch/expiry visible everywhere
