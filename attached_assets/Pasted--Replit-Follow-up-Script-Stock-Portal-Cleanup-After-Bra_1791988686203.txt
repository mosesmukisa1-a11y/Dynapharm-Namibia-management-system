## Phase 4: Cost Evidence Classification

Do not treat `0` as valid original received cost unless explicitly approved.

Add/normalize cost evidence status:

```ts
type CostEvidenceStatus = "original" | "partial" | "estimated" | "missing";

function classifyCostEvidence(line: {
  originalReceivedDPC?: number | null;
  originalReceivedCost?: number | null;
  estimated?: boolean;
  zeroCostApproved?: boolean;
}): CostEvidenceStatus {
  const hasDpc =
    line.originalReceivedDPC !== null &&
    line.originalReceivedDPC !== undefined &&
    (Number(line.originalReceivedDPC) > 0 || line.zeroCostApproved);

  const hasCost =
    line.originalReceivedCost !== null &&
    line.originalReceivedCost !== undefined &&
    (Number(line.originalReceivedCost) > 0 || line.zeroCostApproved);

  if (hasDpc && hasCost) return "original";
  if (hasDpc || hasCost) return "partial";
  if (line.estimated) return "estimated";
  return "missing";
}
```

Valuation must display:

- Original DP value
- Estimated DP value
- Missing DP units
- Original CIF value
- Estimated CIF value
- Missing CIF units

Acceptance:

- Finance and Stock Valuation agree on missing original-evidence units or clearly explain scope differences.
- Historical sales are not repriced from today’s catalogue.

## Phase 6: Transfer And Return Status Cleanup

Normalize internal statuses before rendering.

```ts
const STATUS_LABELS: Record<string, string> = {
  pending: "Pending",
  pending_gm: "Pending GM",
  approved: "Approved",
  dispatched: "Dispatched",
  in_transit: "In Transit",
  received: "Received",
  delivered: "Delivered",
  partially_received: "Partially Received",
  rejected: "Rejected",
  returned: "Returned",
  cancelled: "Cancelled",
};

function cleanStatus(status: string) {
  const raw = String(status || "").replace(/^\$/, "").trim().toLowerCase();
  return STATUS_LABELS[raw] || raw.replace(/_/g, " ");
}
```

Required:

- Remove raw `$delivered`, `$received`, `$approved`.
- Never show `Rejected` and `Approved` for the same actionable transfer.
- If status conflict exists, disable action and show `Status conflict detected`.
