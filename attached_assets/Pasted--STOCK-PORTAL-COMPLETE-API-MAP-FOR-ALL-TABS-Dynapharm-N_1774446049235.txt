# 5. REQUIRED MATH / BINDING RULES

## A. Any blank or zero field must be corrected if data exists

This applies to:

* batch
* expiry
* CIF value
* DPC value
* product count
* stock totals
* pending/in-transit values
* branch stock cards

## B. Warehouse and branch totals must be derived from movement-driven inventory

Do not hardcode card totals.

## C. Pending / In Transit

```text
in_transit_qty = dispatched qty not yet confirmed received
pending_count = number of open dispatch / transfer / request records not completed
```

## D. Overview totals

```text
total_stock_units = sum of all closing qty across company
stock_value_cif = sum(closing_qty × unit_cif)
stock_value_dpc = sum(closing_qty × unit_dpc)
```

## E. Branch stock card

```text
branch_closing_qty = opening + inward - outward
branch_product_count = count(distinct stock lines with qty > 0)
```

## F. Monthly sales

Must use completed/posted sales only.
