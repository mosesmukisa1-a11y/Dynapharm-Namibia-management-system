# 1. CORE STOCK MANAGEMENT STRUCTURE REQUIRED

The stock management module must treat stock as flowing through this real chain:

## A. Supplier Import / Country Stock

Imported stock enters the country through supplier import records.

This must capture:

* Supplier name
* Import reference / GRN / invoice / shipment reference
* Product
* Full product description
* Quantity received
* Batch number
* Expiry date
* CIF cost
* DPC value
* Date received in country
* Destination warehouse
* Supporting notes/documents

This becomes the first official stock entry into the system.

---

## B. Country Stock

Country stock must show:

* all stock currently in Namibia
* grouped by warehouse
* grouped by product
* grouped by batch
* grouped by expiry
* quantities received
* quantities dispatched
* quantities remaining
* stock value by CIF
* stock value by DPC

Country stock must answer:

* what is currently in the country
* which warehouse it is in
* which batch it belongs to
* when it was imported
* what is left
* what is available for issue/distribution

---

## C. Warehouse Stock

Warehouses are the main stock holding points.

Warehouse inventory must track:

* product
* full product description
* batch
* expiry
* quantity in
* quantity out
* quantity reserved
* quantity available
* source import
* destination branch/field if moved out
* DPC value
* CIF value

Warehouses must be the main source of dispatches to:

* branches
* field teams
* other warehouses if applicable

---

## D. Branch Stock

Branch stock must not be shallow.
It must hold **detailed inventory lines**.

Each branch stock line must show:

* product name

* batch number
* expiry date
* quantity received
* quantity sold
* quantity transferred out
* quantity adjusted
* quantity returned
* balance available
* date received
* source warehouse
* stock value if needed
* printable stock line records

Branch stock is a live inventory, not just a summary figure.

---

## E. Field Stock

Field stock must track stock moved to field teams or promoters.

It must show:

* which field officer/team received stock
* product
* batch
* expiry
* quantity issued

* balance
* origin warehouse/branch
* movement date

When selecting stock to distribute from warehouse to branch or field, the system must show:

* product
* available quantity
* batch number
* expiry date
* warehouse location
* quantity available per batch

The dispatcher must choose stock by **batch**, not only by product name.

This is mandatory because the dispatch note must show:

* product

* expiry
* quantity

That same batch and expiry must remain traceable through:

* dispatch note

* branch stock ledger
* reports
* adjustments
* returns

No stock should move blindly without batch linkage.

# 7. OUTBOUND STOCK / INVENTORY CONTROL

Inventory must include proper outbound tracking.

Outbound stock means stock already committed or dispatched out of warehouse/branch.

The system must distinguish:

* physical stock on hand
* stock reserved
* stock dispatched but not yet received
* stock received
* stock sold
* stock returned
* stock expired/damaged

This prevents overstating available stock.
