

# 🚨 BACKEND FOLDER / FILE STRUCTURE MAP FOR STOCK PORTAL APIs

## Dynapharm Namibia System

## Follow-up correction under original paid stock task

## No additional billing

## ❗IMPORTANT

The stock portal already has most of the information in the system, but it is not being displayed correctly because the backend/API/service structure is incomplete or inconsistently bound.

This is the required backend structure so you can encode the stock portal cleanly and stop scattering logic across pages.

The rule is:

* **routes** handle HTTP
* **controllers** validate request + call services
* **services** perform business logic
* **repositories** fetch/store data
* **engines** centralize stock math
* **views/read models** provide dashboard/report-ready data
* **UI** must consume these APIs only

# 2. REQUIRED ROOT STOCK ROUTER

Create one root stock router and mount all stock modules under it.

## File

```text
src/api/routes/stock/index.ts
```

## Example

```ts
import { Router } from "express";
import aiCommandRoutes from "./aiCommand.routes";
import overviewRoutes from "./overview.routes";
import branchStockRoutes from "./branchStock.routes";
import stockReportsRoutes from "./stockReports.routes";
import supplierImportsRoutes from "./supplierImports.routes";
import countryStockRoutes from "./countryStock.routes";
import warehousesRoutes from "./warehouses.routes";
import distributionRoutes from "./distribution.routes";
import transfersRoutes from "./transfers.routes";
import inventoryRoutes from "./inventory.routes";
import ordersRoutes from "./orders.routes";
import monthlySalesRoutes from "./monthlySales.routes";
import countryInventoryRoutes from "./countryInventory.routes";
import valuationRoutes from "./valuation.routes";
import barcodeRoutes from "./barcode.routes";
import aiReorderRoutes from "./aiReorder.routes";
import batchRoutes from "./batch.routes";
import realtimeRoutes from "./realtime.routes";
import fieldStockRoutes from "./fieldStock.routes";
import editRequestsRoutes from "./editRequests.routes";

const router = Router();

router.use("/ai-command", aiCommandRoutes);
router.use("/overview", overviewRoutes);
router.use("/branch-stock", branchStockRoutes);
router.use("/reports", stockReportsRoutes);
router.use("/supplier-imports", supplierImportsRoutes);
router.use("/country-stock", countryStockRoutes);
router.use("/warehouses", warehousesRoutes);
router.use("/distribution", distributionRoutes);
router.use("/transfers", transfersRoutes);
router.use("/inventory", inventoryRoutes);
router.use("/orders", ordersRoutes);
router.use("/monthly-sales", monthlySalesRoutes);
router.use("/country-inventory", countryInventoryRoutes);
router.use("/valuation", valuationRoutes);
router.use("/barcode", barcodeRoutes);
router.use("/ai-reorder", aiReorderRoutes);
router.use("/batches", batchRoutes);
router.use("/realtime", realtimeRoutes);
router.use("/field-stock", fieldStockRoutes);
router.use("/edit-requests", editRequestsRoutes);

export default router;
```
