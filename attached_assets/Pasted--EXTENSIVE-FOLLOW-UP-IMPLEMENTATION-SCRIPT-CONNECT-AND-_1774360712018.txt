# 6. BRANCH STOCK DASHBOARD — REQUIRED CALCULATION RULE

The current branch stock dashboard must calculate values from real movement data.

## For each branch:

### Opening Stock

Opening stock must come from the previous stock position at the start of the selected period.

### + Issued / Received

This must include:

* warehouse dispatches received by branch
* transfer-ins
* returns-in if applicable

### - Sales (units)

This must include:

* walk-in sales
* member sales
* non-member sales
* online fulfilment sales where branch fulfills
* only real stock-deducting transactions

### - Prescription Dispensing

Prescription dispensing must be counted separately where required and must deduct only actually dispensed products.

### - Transfers Out

Any stock moved out from branch must reduce branch stock.

### - Write-offs

Written-off stock must reduce branch stock.

### + Returns

Valid stock returns that come back into branch stock must increase stock.

### Closing Stock

Closing stock must be:
**Opening + Received + Transfer In + Returns - Sales - Dispensed - Transfer Out - Write-off**

### Stock Value

Stock Value must use **DP only**.
